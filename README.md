# Yashwin Sharma — 3D WebGL / WebGPU Portfolio

An immersive, award-winning 3D WebGL / WebGPU interactive portfolio (Frontend Developer | React.js Developer | Next.js Developer).

---

## 🌟 Highlights & Features

- **Cosmic Space Atmosphere**: Deep space nebula dome with dynamic aurora shaders (`#051126`).
- **Interactive Terrain Particles**: Real-time fluid simulation and physics responding to cursor push and drag motions.
- **Volumetric 3D Light Logo**: Custom glowing "YASHWIN" 3D wordmark with chromatic aberration and beam scattering.
- **3D Curved Panoramic "About" Section**: Orbiting camera along a cylindrical path revealing interactive 3D text cards detailing frontend expertise, client work, DSA mastery, and academic credentials.
- **3D Project Gallery & Case Study Engine**:
  - Interactive project tunnel with tactile dragging and hover dynamics.
  - Deep-dive 3D Case Study view for each project featuring:
    - **AI Resume Analyzer** (React.js, Tailwind CSS, Puter.js, pdfjs-dist, Vercel)
    - **Pahalwan Lassi Wale & Sweets** (Next.js, TypeScript, Material UI, Vercel, Technical SEO)
    - **DiscoverSTEM Platform** (Next.js, TypeScript, Tailwind CSS, Material UI)
    - **CMS Launchpad** (React.js, Next.js, Material UI, REST APIs)
    - **1Pooja & Hichandra** (Next.js, Material UI, Technical SEO)
    - **Slater Matsil Corporate Portal** (Next.js, Material UI, TypeScript)
- **Interactive 3D Social Cards**: Direct links to LinkedIn, GitHub, Email, and Phone.
- **Production-Ready & Fully Offline**: All 3D shaders, textures, fonts, and assets are hosted locally without external dependencies.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)

### Run Locally

1. Start the local server:
   ```bash
   npm start
   # or
   npm run dev
   ```

2. Open your browser:
   ```
   http://localhost:3000
   ```
